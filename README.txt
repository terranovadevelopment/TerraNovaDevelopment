IMPORTANT — ONE-TIME FACEBOOK PREVIEW SETUP:
Your public Render URL was not supplied. The six HTML pages contain the marker:
  https://REPLACE-WITH-YOUR-LIVE-SITE-URL
Replace that marker in index.html and articles/article-001.html through article-005.html with your ACTUAL public website origin, e.g. https://your-real-name.onrender.com (no trailing slash).
This is necessary because Facebook requires public absolute og:url and og:image URLs. Until replaced, Facebook previews will not work reliably.
You can use the included set-site-url.ps1 Windows PowerShell script to make the replacements.

After updating, copy the website contents into your local GitHub folder, commit and Push origin. Render will redeploy if Auto-Deploy is enabled. Test by sharing each public article URL in Facebook; Facebook may cache old previews.

Article #005 has been added with its own social preview image.

For EVERY future article: include og:title, og:description, og:image, og:url, and twitter:card, with public absolute URLs and a dedicated preview image.

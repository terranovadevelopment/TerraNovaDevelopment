Terra Nova Development static website — VERSION 009

PUBLISH:
1. Extract this ZIP into your existing local TerraNovaDevelopment GitHub folder, preserving the assets/ and articles/ directories.
2. Set your real public website URL for Facebook sharing. In PowerShell, from the website folder, run: .\set-site-url.ps1 -SiteUrl "https://YOUR-ACTUAL-RENDER-URL.onrender.com" (check script usage).
3. Commit as "Website v009" in GitHub Desktop, then Push origin. Render auto-deploys if enabled.

IMPORTANT: Sharing preview metadata currently contains the placeholder https://REPLACE-WITH-YOUR-LIVE-SITE-URL. It MUST be replaced with your real site URL before Facebook previews will work.
